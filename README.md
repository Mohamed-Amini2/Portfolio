
Portfolio Website - Mohamed Amini
A modern, high-performance personal portfolio website built with React, Vite, and Tailwind CSS. This project features a dark-themed aesthetic, responsive design, and smooth typography to showcase software engineering work and experience.

Tech Stack:

Framework: React (v19)
Build Tool: Vite
Styling: Tailwind CSS (v4)
Icons: Lucide React
Routing: React Router DOM
Language: TypeScript 


Features:

Responsive Design: Fully fluid layout that adapts from mobile to large desktop screens using Tailwind's grid and flexbox systems.
Dynamic Content: Experience, Education, and Skills are populated dynamically to ensure easy updates and scalability.
Custom Typography: Integrated unique font stack including Bitcount Grid Single, Libre Baskerville, and Caesar Dressing.

Interactive Elements:

Hover effects on project cards and navigation.
Functional-looking contact form (ready for API integration).
Smooth scrolling and layout transitions.
Fonts:

The project loads the following Google Fonts to create a distinct visual identity:
Headings/Creative: Bitcount Grid Single
Body/Text: Libre Baskerville
Accents: Caesar Dressing, Monsieur La Doulaise
